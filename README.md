# RAKUFULL 🎵

> 会計業務を楽しく、心地よく。

## これは何？

クラウド会計ソフトの入力画面に、サウンドエフェクト・環境音・テーマカラーを追加する **非公式Chrome拡張機能**です。

DX化・自動化がトレンドの今、あえて「入力体験そのものを楽しくする」というコンセプトで作りました。

会計事務所に勤める中で、個人事業主の方々が会計入力を苦手とする場面を多く見てきました。めんどうな記帳の時間が、少しでも心地よい時間になればと思い開発しました。

## v2.0 の新機能

### モードプリセット
「リラックス・集中・夜作業」の3つから選ぶだけで、画面全体の雰囲気が切り替わります。

| プリセット | 雰囲気 |
|-----------|--------|
| 🌿 リラックス | 明るく温かみのある黄色系 |
| 🔥 集中 | 安定感のある青系（デフォルト） |
| 🌙 夜作業 | 深く落ち着いた暗青系 |


### シンプルなUI
初回表示ではモード・環境音・音量の3項目のみ表示。詳細設定は折りたたみに格納し、会計ソフト本体の操作を邪魔しない設計にしました。

## 機能一覧

- 🕐 **モードプリセット** — リラックス・集中・夜作業の3種類
- 🌿 **環境音** — 波・焚火・雨をBGMとして流せる
- 🎹 **入力SE** — キーを押すたびに心地よい音（ピアノ・マリンバ・ポップ・8bit）
- ✨ **登録エフェクト** — 登録ボタンを押すとコイン＆コンフェッティが舞う
- 🔥 **集中モード** — 画面を落ち着いたトーンに切り替え
- 🖱️ **コンソールパネル** — 画面上を自由にドラッグして移動可能

## 対応ソフト

- やよいの白色申告 オンライン
- やよいの青色申告 オンライン
- freee会計(対応予定）

## インストール方法

1. [最新版のZIPをダウンロード](https://github.com/torineco/rakufull/releases)
2. ZIPを解凍する
3. Chromeで `chrome://extensions/` を開く
4. 右上「**デベロッパーモード**」をオンにする
5. 「**パッケージ化されていない拡張機能を読み込む**」→ 解凍したフォルダを選択
6. やよいまたはfreeeの画面を開くと右下にコンソールパネルが表示されます

※ Chromeブラウザのみ対応しています。
※ アンインストールは `chrome://extensions/` から削除するだけで完全に元に戻ります。
